# v0.5.1 验证记录

日期：2026-09-14

## 修复

用户反馈聊天输入时顶部内容与状态栏重叠、输入框下方大块留白。原聊天页使用默认窗口适配的全屏 Dialog，同时在底部应用键盘和导航栏 padding。改为由统一 CompanionDialog 容器管理系统栏及键盘占用区域，子页面不再单独添加底部避让。

- Dialog 使用 decorFitsSystemWindows=false；由 Compose 窗口逻辑设置对应系统版本的软键盘调整方式。
- 在弹窗内部读取 WindowInsets.safeDrawing，避免读取到主 Activity 窗口的键盘状态。
- 根容器应用并消费安全区域；顶部栏、输入区和编辑保存按钮位于同一个可用区域。
- 同步修复伴侣聊天、人设编辑、模型配置页面。
- 模型配置页改用 SecureFlagPolicy.SecureOn，防止手动设置的安全标志被弹窗刷新覆盖。
- 数据库、网络请求协议及配置保存格式均未更改。

依据：[Android 官方窗口边距与消费说明](https://developer.android.com/develop/ui/compose/system/insets-ui)。
