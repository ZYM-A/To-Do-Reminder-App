## 使用与升级

底部为“日程、纪念日、日记本”。原今日、日程和全部待办三个入口在“日程”页内以“今日、日历、全部”切换。各页添加按钮分别打开待办、纪念日或日记编辑页。

日记按日期存储，可同日多篇、补写日期、搜索、编辑和删除；标题可选、正文必填。点保存才写入 SQLite；返回时有修改会询问是否放弃，界面状态恢复测试覆盖未保存标题和正文。此机制不等同于持久自动草稿。

数据库从 v3 升级到 v4 时新增 diaries 表和日期排序索引，保留旧任务与纪念日；从 v1 / v2 直接升级也已覆盖。所有数据操作沿用后台线程和串行锁。

日记不联网、不云同步，当前没有导出功能。卸载或清除应用数据会删除日记。发布包沿用原签名，可直接覆盖安装旧版。
