# 日常 v0.4.0 · 三栏导航与日记本

底部导航调整为 **日程、纪念日、日记本**。

- 原来的“今日、日程、全部”合并进“日程”页，在页内切换“今日 / 日历 / 全部”。
- 保留原有待办编辑、完成、重复和提醒功能，以及公历 / 农历纪念日。
- 新增日记本，支持按日期写日记、同日多篇、阅读编辑、关键词搜索和删除确认。
- 标题选填、正文必填，保留段落换行；返回时提示未保存的修改。
- 旧数据自动升级保留，使用相同签名，可直接覆盖安装 v0.1.0—v0.3.0。

下载 Assets 中的 **richang-v0.4.0-debug.apk**；不要卸载旧版。可用 SHA256SUMS.txt 核对下载文件。

日记只保存在本机，目前没有云同步或导出；卸载或清除应用数据会删除记录。开发测试版，尚未完成真机验收。
