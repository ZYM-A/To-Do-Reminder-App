「日常」首个安卓开发测试版，适用于 Android 8.0 及以上。

## 下载与安装

下载下方附件 **richang-v0.1.0-debug.apk**，传到安卓手机后打开安装。首次使用请开启通知和准时提醒权限。

`Source code` 附件是源码，不是手机安装包。`SHA256SUMS.txt` 用于核对安装包完整性。

## 本版功能

- 今日待办、日历及全部任务视图。
- 添加、修改、删除和完成任务，本地保存。
- 准时或提前提醒，每天／每周重复。
- 系统提醒权限入口和重启后恢复提醒。
- 中文界面，支持浅色、深色主题。

## 验证与限制

编译及 APK 签名校验通过，14 项单元测试全部通过，Android Lint 无错误和警告。

本版使用 Debug 签名，供开发试用。尚未完成真机界面与锁屏提醒验证；未做品牌专属适配。数据保存在本机，卸载或清除数据会删除任务，暂无导出和云同步功能。
