# 日常 v0.3.0 · 农历 / 公历纪念日

在 **纪念日 → 添加 / 编辑纪念日 → 历法** 中选择公历或农历。

- 新增独立农历年、月、日选择器，支持 1900—2100 年、闰月和大小月。
- 同时显示农历与对应公历日期，切换历法保留同一个实际日期。
- 每年重复按所选历法计算；没有同名闰月时按普通月、没有三十时按廿九纪念。
- 原有纪念日保持公历，旧待办和纪念日数据可直接升级保留。

下载 Assets 中的 **richang-v0.3.0-debug.apk** 安装。与前两个版本使用相同签名，可以直接覆盖安装，无需卸载。SHA256SUMS.txt 可用于核对下载文件。

开发测试版；农历计算、数据库迁移及界面交互已通过自动验证，尚未完成真机端到端测试。纪念日当前不发送到点通知。
