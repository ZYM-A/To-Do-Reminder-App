# 日常 v0.5.0 · AI 伴侣基础聊天

本版把 AI 伴侣入口升级为可配置的文字聊天功能。底部依旧只有日程、纪念日、日记本。

- 编辑伴侣名字、对你的称呼、性格和说话风格。
- 自填 HTTPS 接口、密钥和模型 ID；支持服务商预设、自定义接口、测试连接及获取模型列表。
- 密钥和接口配置用 Android Keystore / AES-GCM 加密保存在本机，密钥页禁止截图。
- 支持文字聊天、本地话题记录、话题切换与删除、失败消息手动重试。
- 新增成功消息数、回复数、活跃天数、相识天数和服务商返回的 token 用量统计。
- 首次发送及修改人设、模型配置或切换话题后，确认接收方和数据范围；仅发送当前消息、人设与当前话题有限上下文，不自动读取日记、日程或纪念日。

## 安装和使用

下载 **richang-v0.5.0-debug.apk**，可覆盖安装旧版，无需卸载；沿用原测试签名。应用版本为 0.5.0（versionCode 6）。

打开右上角爱心 → 伴侣菜单 → 模型设置，填写自己的接口、密钥和模型 ID，保存后返回聊天。费用由你选择的服务商收取。密钥只在手机填写，无需提供给开发者。

## 说明

聊天及人设正文保存在应用私有数据库，目前不额外加密正文；配置和密钥加密保存。卸载或清除数据会丢失本机记录，目前无导出与云同步。删除本机记录不会删除服务商的数据。

本版不含长期记忆、语音、图片或主动消息。界面、数据库、加密流程和接口协议通过自动化模拟测试；尚未使用真实密钥验证服务商，也尚未完成实体手机验收。特定服务商和模型的兼容性需在手机上验证。

仓库与安装包只包含通用代码、文档和资源，不包含个人密钥、照片、人设、聊天或日记记录。完整检查范围见仓库内的版本验证记录。
