# 日常 v0.5.1 · 聊天键盘布局修复

修复进入聊天并弹出键盘后，页面顶部上移、状态栏与文字重叠，以及输入框和键盘之间出现大块空白的问题。

- 聊天页由统一容器处理系统栏与键盘空间，去除底部重复避让。
- 人设编辑和模型设置使用相同的全屏窗口处理，保存按钮随可用高度调整。
- 模型设置页固定启用禁止截图，防止安全标志被弹窗刷新覆盖；保留密钥遮挡。
- 新增不同键盘高度、收起键盘和窗口缩放模式的回归检查。

下载 **richang-v0.5.1-debug.apk** 直接覆盖安装，无需卸载。沿用原签名，版本号 0.5.1（versionCode 7）。数据库和模型配置格式不变。

自动测试模拟了键盘占用空间；仍需在实际手机和输入法上确认显示效果。安装后请打开聊天，点击输入框，检查顶部返回/菜单是否可见、输入区与键盘之间是否还有异常空白，再收起键盘检查页面恢复。

发布不包含用于排查问题的个人截图或用户数据。
